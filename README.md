# 我们的小事

经典 Hello Kitty 风格的恋爱手账：红白配色、红色格纹、原始角色图与按月归档的回忆卡片。没有预填虚构的恋爱记录。

## 本机使用

在此目录运行 `python3 -m http.server 8000`，浏览器打开 `http://localhost:8000`。保持使用同一个地址和浏览器，即可持续查看本机记录。无需安装依赖或构建。

- 点击「记一件小事」，填写标题、日期、所属系列、故事和地点。
- 一条回忆最多添加 12 张照片，单张原图不超过 30 MB；自动缩小至最长边 1800 像素并转成 JPEG，GIF 会保存为静态图片。
- 回忆按日期倒序、按月展示，支持系列筛选、搜索、照片放大和编辑。查看全部照片与完整故事可进入「查看 / 编辑」。
- 保存后自动展示在网站，重新打开同一个网址即可继续查看，无需导入或导出。

## 数据保存

文字与照片保存在当前浏览器、当前站点的 IndexedDB，不会上传到服务器。清理站点数据、使用其他浏览器、换网址或设备后，不会自动出现原记录。请勿清理此站点的浏览器数据。删除回忆前会提示确认，删除后无法恢复。

当前版本可发布到静态网站托管平台，但发布网站不会同步本机记录。若需两个人在不同设备共同记录，需要后续增加身份验证与云端数据库、图片存储。

使用系统中文字体，角色图片随网站本地加载，浏览时不依赖外部服务。

角色图片来源：[三丽鸥官方 Hello Kitty 角色页](https://www.sanrio.co.jp/characters/hellokitty/)，原图地址为 `https://www.sanrio.co.jp/wp-content/uploads/2022/06/mv-hellokitty.png`。角色及图片权利归原权利人所有。

## 文件

- `index.html`：页面结构、对话框与经典角色图引用。
- `style.css`：桌面、移动端样式。
- `app.js`：回忆编辑、图片处理、本机存储。

## 回忆系列

- 第一次：第一次牵手、拥抱、一起出游等。
- 心动回忆：惊喜、告白、感动与怦然心动的瞬间。
- 日常：吃饭、散步、约会、旅行与平凡生活。
- 纪念日：生日、恋爱周年与特别日期的记录。

点击系列卡片查看对应记录，再点击「添加回忆」会预选当前系列；在全部回忆中新增时默认选择日常。每条记录只属于一个系列，可随时编辑调整。

旧记录的「约会」「旅行」显示为「日常」，「小事」显示为「心动回忆」，「纪念日」保持原系列。兼容转换在读取时完成，保存编辑后才更新该记录的原始分类字段。

## 在线访问

网站通过 GitHub Pages 发布，仓库根目录即为静态站点目录。在线版和本机版是不同的站点地址，不会自动共享浏览器里的回忆。
